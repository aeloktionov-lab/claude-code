# ФОРМА.PRO — продажа корпоративной одежды

Полный проект интернет-магазина корпоративной одежды: сайт с каталогом, заявками и
базовой админкой + пакет бизнес-документов для реального запуска.

## Структура проекта

```
docs/                бизнес-план, бренд-гайд, чек-лист юридического запуска
data/                каталог товаров (products.json) и настройки бренда (config.json)
server/              бэкенд Express + SQLite (API, приём заявок)
public/              фронтенд: главная, каталог, карточка товара, заявка, контакты, админка
```

## Быстрый старт (локально)

```bash
cd server
npm install
ADMIN_PASSWORD=your-secret-password npm start
```

Откройте http://localhost:3000 — сайт и API работают на одном порту (Express отдаёт
и статику из `public/`, и `/api/*`).

Админка с заявками: http://localhost:3000/admin.html — браузер попросит логин/пароль
(логин любой, пароль — значение `ADMIN_PASSWORD`).

## Как менять контент без программиста

- **Товары и цены** — `data/products.json`. Добавьте объект по образцу существующих,
  положите фото в `public/img/products/` и укажите путь в поле `img`.
- **Название бренда, телефон, email, цвета** — `data/config.json`, применяется на
  всех страницах автоматически.
- **Тексты бизнес-плана/бренда** — `docs/*.md`.

## Деплой

Подходит любой хостинг с Node.js (Render, Railway, VPS + PM2/systemd, Yandex Cloud):

1. Скопируйте репозиторий на сервер, `cd server && npm install`
2. Задайте переменные окружения: `PORT` (по умолчанию 3000), `ADMIN_PASSWORD`
3. Запустите `npm start` (в проде — через PM2/systemd для автоперезапуска)
4. Настройте домен и HTTPS (например, через Nginx + Let's Encrypt, либо встроенный
   SSL хостинг-провайдера)

База данных — файл SQLite (`server/data.sqlite`), создаётся автоматически при первом
запуске. Для продакшена делайте регулярный бэкап этого файла.
