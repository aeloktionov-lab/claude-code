# Бренд-гайд

Источник: реальная дизайн-система CROID из Figma (файл `croidfigmaexportbundled.html`,
загруженный в сессию 29.08.2026). Ниже — токены и компоненты из неё, уже перенесённые
в `public/css/style.css`. Логотип — настоящий SVG-вектор из файла, лежит в
`public/img/logo.svg`.

## Название и логотип
**croid.ru** — логотип представляет собой готовый векторный wordmark «CROID.RU»
(белая заливка, для тёмного фона). Меняется он только заменой файла
`public/img/logo.svg` — текст нигде не генерируется программно.

## Цвет
Тёмная тема — «Ink», один акцентный цвет. Никакого второго акцента не предусмотрено
дизайн-системой.

| Токен | HEX | Назначение |
|---|---|---|
| `--ink` | `#1C1C1C` | фон сайта (никогда не чистый чёрный) |
| `--ink-2` | `#262626` | поднятые поверхности — карточки, инпуты |
| `--ink-3` | `#2F2F2F` | hover на тёмных поверхностях |
| `--orange` (`--accent`) | `#CE7E4C` | единственный акцент — кнопки, CTA, цена |
| `--orange-ink` | `#A86334` | hover/active акцента |
| `--paper` | `#F4F1EC` | редкая светлая поверхность (инверсия, не используется на сайте пока) |
| `--fg-1` | `#FFFFFF` | основной текст |
| `--fg-2` | `rgba(255,255,255,.72)` | вторичный текст |
| `--fg-3` | `rgba(255,255,255,.48)` | подписи, лейблы |

## Типографика
Дизайн-система использует **Druk Text / Druk Text Wide** (Letters from Sweden) —
это платный коммерческий шрифт. В файле из Figma он был встроен как превью-шрифт
для отображения макета, но **я не стал переносить этот файл на сайт**: у такого
превью нет отдельной веб-лицензии, и раздавать его посетителям сайта без неё —
нарушение лицензии шрифта, а не техническая мелочь.

Вместо этого на сайте сейчас:
- **Inter** (500–900) — замена для Druk Text/Druk Text Wide, свободный, с полной
  поддержкой кириллицы, схожая насыщенность в жирных начертаниях
- **JetBrains Mono** (500, 700) — использован как есть, это ровно тот же шрифт,
  что и в оригинальной системе (для лейблов, тегов, моно-текста), он свободный
  (Apache 2.0/OFL) и легально встраивается

Если у вас есть веб-лицензия на Druk Text — пришлите `.woff2`-файлы, я подключу
их вместо Inter буквально в одном месте (`--font-sans` / `--font-display` в
`public/css/style.css`), больше ничего трогать не придётся.

Шкала размеров (используется в HTML напрямую, не как токены):
- H1 (герой) — `clamp(32px, 5vw, 56px)`, вес 800, трекинг `-0.03em`
- H2 (заголовки секций) — `28px`, вес 800
- Body — `17px` при весе 500

## Кнопки, поля, теги, карточки
Взято из спецификации компонентов дизайн-системы:
- Радиус скругления везде **2px** («почти прямоугольные»), кроме тегов — там `999px` (pill)
- Кнопки — высота 52px, без теней; основной вариант залит акцентом, `.btn.secondary` — с обводкой
- Карточки (`.card`, `.product-card`, `.cat-card`) — заливка `--ink-2`, обводка `--line`
  (`rgba(255,255,255,.08)`), **без теней** — система принципиально не использует box-shadow
  для карточек
- Инпуты — заливка `--ink-2`, обводка `--line`, фокус — обводка `--fg-1`

## Позиционирование
«Корпоративная одежда без головной боли»: от поло с логотипом до спецодежды —
один поставщик, один менеджер, понятные сроки. Ключевое отличие модели: **шьём
под заказ, склада готовых изделий нет** — это сознательный выбор, а не ограничение,
подавать как «точное попадание в бренд клиента», а не как недостаток скорости.
