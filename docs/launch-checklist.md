# Чек-лист запуска в реальности

Это шаги, которые я не могу выполнить за вас (нужны ваши паспортные данные, подпись,
личный визит/электронная подпись). Всё остальное — сайт, каталог, тексты, документы —
уже подготовлено в этом проекте.

## 1. Юридическое оформление
- [ ] Выбрать форму: ИП (проще, быстрее — рекомендовано для старта) или ООО (если сразу
      несколько учредителей или нужны крупные B2B-контракты с НДС)
- [ ] Подать заявление на регистрацию через сайт ФНС (nalog.ru) или Госуслуги —
      электронно это бесплатно (без гос. пошлины)
- [ ] Выбрать код ОКВЭД: **46.42** (оптовая торговля одеждой) как основной,
      доп. — **14.1** (пошив одежды), если планируется собственное производство
- [ ] Выбрать систему налогообложения: УСН «доходы» 6% — самый простой вариант для старта

## 2. Расчётный счёт и приём платежей
- [ ] Открыть расчётный счёт (Тинькофф Бизнес, Т-Банк, Сбербанк — можно онлайн за 1 день)
- [ ] Подключить эквайринг/приём платежей для B2B (счета на оплату для юрлиц — есть у любого банка)
- [ ] Опционально: подключить ЮKassa/CloudPayments, если понадобится приём онлайн-оплаты
      физлицами на сайте

## 3. Поставщики
- [ ] Найти 2–3 швейных производства/поставщика тканей (маркетплейсы B2B, отраслевые
      выставки, «Текстильлегпром»)
- [ ] Запросить образцы и прайсы, сверить с ценами в `docs/business-plan.md`
- [ ] Заключить рамочный договор поставки с выбранным поставщиком

## 4. Домен и хостинг
- [ ] Зарегистрировать домен (например, `forma.pro`, `forma-pro.ru`) — reg.ru, nic.ru
- [ ] Развернуть сайт из этого репозитория на хостинге (см. `README.md`, раздел «Деплой»)

## 5. Первые продажи
- [ ] Заполнить `data/products.json` реальными позициями, ценами, фото
- [ ] Указать реальный email/телефон в `data/config.json` — туда падают заявки с сайта
- [ ] Сделать первые 10–20 холодных обращений по списку компаний из целевых ниш
- [ ] Настроить рекламный кабинет (Яндекс.Директ) и залить первую кампанию

## 6. Бухгалтерия
- [ ] Подключить онлайн-бухгалтерию (Эльба, Моё дело) — автоматизирует отчётность на УСН
