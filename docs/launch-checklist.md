## 5. Уведомления о заявках
Без этого шага заявки видны только вручную в `/admin.html` — легко пропустить.
- [ ] Написать [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → скопировать
      токен вида `123456:ABC-...` → это `TELEGRAM_BOT_TOKEN`
- [ ] Написать своему новому боту любое сообщение (иначе он не сможет писать вам первым)
- [ ] Узнать свой `chat_id`: написать [@userinfobot](https://t.me/userinfobot) — он
      пришлёт ваш числовой ID → это `TELEGRAM_CHAT_ID`
- [ ] Вписать оба значения в `server/.env` на сервере (шаблон — `deploy/env.example`)
      и перезапустить сервис (`systemctl restart croid`)
